Use this directory as the operational design-system source for future branding, design, and frontend agents.

## Token files

- `tokens/brand-tokens.json`
- `tokens/brand-tokens.css`

## Which agents should read what

- Branding agents: `brand-application.md`, `design-principles.md`, `agent-rules.md`
- UI/design agents: `design-tokens.md`, `page-patterns.md`, `component-foundations.md`
- Frontend/code agents: `design-tokens.md`, `component-foundations.md`, token files
- Handoff/design-ops agents: `design-handoff.md`

## Scope

This package defines:

- visual principles
- web brand application
- token system
- reusable page and UI patterns
- governance rules for future agents

It does not define final Figma screens or a pixel-perfect component library.
