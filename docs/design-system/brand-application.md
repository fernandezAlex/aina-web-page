# Brand Application

## Authority order

Apply the brand in this order:

1. official brand manual
2. project content and context docs
3. best web signals from `siasha.org`

## Brand translation to web

### What the website should feel like

- institutional
- hopeful
- rigorous
- warm
- documentary
- conversion-capable

### What the website should not feel like

- startup-like
- charity-campaign cliché
- volunteer tourism
- overly corporate and emotionally distant

## Color use on web

Primary web color roles:

- red for identity, key CTAs, links, emphasis
- orange for warmth, hover emphasis, select highlights
- warm beige for soft surfaces and non-clinical backgrounds
- dark neutrals for readable text

### Usage rules

- red is the anchor color, not orange
- orange is a controlled accent, not a second dominant system
- beige should support warmth without reducing contrast
- keep document and transparency sections visually sober

## Typography application

Brand intent from the manual:

- body copy should feel simple and human
- headings should feel geometric, clear, and strong

On the web, prioritize:

- readability first
- stable multilingual rendering
- generous spacing around headings
- short strong headlines

## Photography application

Use:

- real programme photography
- portraits with dignity
- images showing activity, care, learning, and presence
- local staff and women leadership visibly

Avoid:

- stock NGO imagery
- heavily filtered visuals
- pain-first storytelling images
- decorative placeholders replacing real context

## Voice and visual relationship

When the tone is more institutional, the visual system should not become colder.

When the visuals become warmer, the information architecture should not become less precise.

The balance to preserve is:

- rigorous copy
- warm composition
- trustworthy structure

## Brand tension to preserve well

The best expression of the brand combines:

- the formal discipline of the brand manual
- the emotional clarity and better digital instinct visible in `siasha.org`

Future agents should combine both rather than picking one extreme.
