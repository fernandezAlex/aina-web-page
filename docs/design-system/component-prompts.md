# Component Prompts

Use these prompts to generate component- or pattern-level explorations in Figma AI, Stitch, Claude Design, or similar tools.

## Global instruction to prepend

```text
Design UI patterns for Si Asha Foundation.

Brand: hopeful, serious, warm, trustworthy, institutional but human.
Do not create generic NGO UI, startup SaaS UI, or visually noisy layouts.

Use these colors:
- #BD0833 primary
- #EB6B2F accent
- #FFA952 accent soft
- #9C5E03 earth
- #E8CEB0 warm surface
- #FFFFFF base
- #111111 text primary
- #333333 text secondary

Use spacious layout, clear hierarchy, real-photo-driven design, and accessible CTA logic.
```

## Institutional hero

```text
Create 3 variations of an institutional homepage hero for Si Asha Foundation.

Requirements:
- strong mission headline
- short supporting text
- 1 primary CTA
- 1-2 secondary CTAs
- real photography
- emotionally strong but credible

Compare different hierarchy options, not different brand directions.
```

## Impact stats band

```text
Design an impact stats band for Si Asha Foundation.

Requirements:
- display 4 key metrics clearly
- large numbers first
- short labels
- high readability
- should feel institutional and optimistic
```

## Programme cards

```text
Design a programme cards section for Si Asha Foundation.

Requirements:
- image-led cards
- title and short summary
- clean spacing
- works for multiple programme areas
- should feel warm, documentary, and structured
```

## Location cards

```text
Design a location/centre cards section for Si Asha Foundation.

Requirements:
- name of centre
- city/province summary
- key facts
- optional CTA
- clear, structured, not cluttered
```

## Transparency document list

```text
Design a transparency document list or document cards pattern for Si Asha Foundation.

Requirements:
- title first
- document type and year visible
- download/view action obvious
- minimal decoration
- should feel rigorous and trustworthy
```

## Team pattern

```text
Design a team and board presentation pattern for Si Asha Foundation.

Requirements:
- dignified portrait
- name
- role
- grouped by team structure
- clean and trustworthy layout
- no collage or chaotic mosaic aesthetic
```

## CTA band

```text
Design a reusable CTA band for Si Asha Foundation.

Requirements:
- one strong proposition
- one primary CTA
- up to two secondary actions
- strong but elegant visual emphasis
- must work between institutional content sections
```

## Support option cards

```text
Design support option cards for Si Asha Foundation.

Requirements:
- separate paths for Exclusive Member, General Member, Donate, Volunteer
- each option must feel distinct
- title and short explanation
- amount visible where relevant
- clear CTA
```

## Story block

```text
Design a story block for Si Asha Foundation.

Requirements:
- portrait or contextual image
- person name or story title
- short narrative summary
- dignity-first presentation
- emotional but not manipulative
```

## Form shell

```text
Design a reusable public form shell for Si Asha Foundation.

Requirements:
- clear heading
- grouped fields
- labels always visible
- payment choice section visually distinct
- calm and trustworthy appearance
- mobile-friendly
```

## Payment-method selector

```text
Design a payment-method selector block for Si Asha Foundation.

Requirements:
- options for Khalti, eSewa, Bank Transfer / QR, Cash
- clearly distinguish interactive payment versus manual payment
- easy to understand on mobile
```
